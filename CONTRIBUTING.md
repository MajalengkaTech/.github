# Panduan Kontribusi

Terima kasih telah berkontribusi pada Mejalengka-Tech.

## Jenis kontribusi

Anda dapat membantu melalui:

- Melaporkan bug
- Mengusulkan fitur
- Memperbaiki dokumentasi
- Membuat desain
- Menulis kode
- Menguji proyek

## Alur kontribusi

1. Baca README dan dokumentasi proyek.
2. Buat Issue sebelum mengerjakan perubahan besar.
3. Buat branch baru dari branch utama.
4. Gunakan nama branch yang jelas.
5. Buat Pull Request.
6. Tunggu proses review.
7. Lakukan perbaikan jika diperlukan.

## Contoh nama branch

- `feature/nama-fitur`
- `fix/nama-masalah`
- `docs/perbaikan-dokumentasi`

## Standar pull request

Pull request harus menjelaskan:

- Masalah yang diselesaikan.
- Perubahan yang dibuat.
- Cara menguji perubahan.
- Screenshot jika menyangkut tampilan.
